# Failure-mode analysis of the seven single-SDK variants

Mirroring the Chapter-4 multi-agent case studies (Cases A–D), this report
profiles each single-SDK variant on the 16-image reaction-extraction benchmark.
For every variant we identify the three images with the lowest Product IoU
under the existing evaluation pipeline and, where it differs, the image with
the lowest Partial F1 (Jaccard ≥ 0.5, stereo-stripped). Each low-scoring image
is then classified into one of the agreed failure categories on the basis of
RDKit-canonicalised predicted-vs-gold SMILES pairs.

## Reproduction

All numbers are produced by the helper:

- `Collective_autogen/eval/failure_mode_analysis.py`

which imports `evaluate` from `Collective_autogen/eval/metrics.py` (the same
canonicalisation + matching helpers used by the headline scoreboard) and the
`figure_extraction_to_record` translator from
`Single_SDK_agent/scripts/eval_via_collective.py`. It dumps the full per-image
metric set plus the bipartite-best matched SMILES pairs into the raw artefact
referenced below; the markdown sections were written by inspecting that
artefact. No source-of-truth files were modified.

Inputs read:

- Predictions: `Single_SDK_agent/benchmark_runs/<variant>/*.json` and the
  matching `*.meta.json` (for step-ceiling detection):
  `run01_opus4.7`, `run_opus46`, `run_gpt54`, `run_gpt55`,
  `run_gemini31propreview`, `run_gemini3flash`, `run_grok43`.
- Gold: `Collective_autogen/eval/ground_truth/<stem>.json` for each predicted
  stem (same filenames as predictions).
- Metric code: `Collective_autogen/eval/metrics.py`.
- Translator: `Single_SDK_agent/scripts/eval_via_collective.py`.

Raw per-image artefact (re-generated by running the helper):

- `outputs/failure_modes_raw.json`

## A note on “Product IoU = 0 but Partial F1 > 0”

Several rows below have `prodIoU = 0.0` together with a high `partialF1`.
This is the expected signature of a **pure stereo-error**: the strict
product-IoU set requires exact canonical-SMILES equality (chirality
included), whereas `partial_match_f1` strips stereo before computing
Jaccard. When every product is constitutionally correct but every
α-carbon stereo descriptor is flipped, prodIoU collapses to 0 while
partialF1 stays near 1. We tag those cases as `stereo_error` rather than
`connectivity_misread`.

## Cross-variant patterns

### (a) Images that fail on ≥ 3 variants with the same category

- **`ACScat_2020.pdf_page002_table_01_s0.88` — `connectivity_misread`**
  appears in the lowest-3 set for **6 of 7 variants** (Opus 4.7, Opus 4.6,
  GPT-5.4, GPT-5.5 indirectly, Gemini 3.1 Pro, Gemini Flash; Grok did not run
  this image in the lowest-3 by IoU but still flagged the same mismatch in
  its full per-image data). In every case the same `(Cc1ccccc1)` benzyl
  side-chain is emitted against a gold that encodes `(C(=O)c1ccccc1)` benzoyl.
  All seven variants make the same chemistry call against the image; the
  systematic mismatch points to **a defect in the gold annotation for this
  table** (the `additional_info` field on each row records `"substrate 1b
  (R = Bn)"`, i.e. R = benzyl, but the SMILES on the same row encodes
  benzoyl), not a variant-specific extraction error.
  **This gold defect is known and intentionally left unpatched at the time
  of writing; the rows are kept in the lowest-3 lists above for traceability
  rather than as outstanding model failures.**

- **`ACScat_2020.pdf_page003_picture_01_s0.93` — `stereo_error`** appears in
  the lowest-3 set for **5 of 7 variants** (Opus 4.7, Opus 4.6, GPT-5.5,
  Gemini Flash, Grok). Every variant produces constitutionally identical
  dipeptide products but flips at least the second-residue α-carbon
  descriptor (`[C@@H]` → `[C@H]` or vice versa). The image displays a Boc-Xaa-Yaa-OBn
  amino-acid coupling table where the second residue is drawn with the same
  wedge-style stereobonds for both `L` and `D` rows; this is the type of
  ambiguous wedge call that all multimodal models in the benchmark mis-read.

- **`GC_2015.pdf_page003_picture_03_s0.71` — `stereo_error` and
  `methylene_shift`** appears in the lowest-3 for **4 of 7 variants** (GPT-5.5
  with methylene_shift; Gemini 3.1 Pro, Gemini Flash, Grok with stereo_error).
  The proline α-stereo on Boc-Pro is consistently mis-called by all three
  Gemini/Grok variants, and GPT-5.5 additionally inserts an extra methylene
  in the N-benzyl amide.

- **`GC_2015.pdf_page004_table_01_s0.81` — partial-F1-only failure (`other`,
  hallucinated reactants on a product-only gold)** appears as the lowest
  Partial-F1 row for **both Gemini Flash and Grok**. Strictly two variants,
  so below the “≥3” threshold for systematic image-issue, but the pattern is
  identical and worth flagging.

### (b) Failure categories that dominate one variant but not others

- **GPT-5.4 / GPT-5.5: `methylene_shift` is the dominant category.** Both
  OpenAI variants repeatedly emit a phenethyl group (`NCCc1ccccc1`) where the
  gold draws benzyl (`NCc1ccccc1`). On GPT-5.4 this shows up at scale on
  CEJ_2016 page 002 (×14) and ACScat page 002 (×13). No other variant places
  methylene_shift as its dominant per-image failure category.

- **Opus 4.7: `stereo_error` dominates the partialF1-high / prodIoU-low cluster.**
  Opus 4.7 is uniquely good at writing constitutionally correct SMILES — its
  ACScat-page-003 and CEJ-page-004 failures are almost pure stereo flips
  (constitution_match ≫ soft_match). The other strong variant (Opus 4.6) drops
  in two cases to `connectivity_misread` instead, so this is an Opus-4.7
  signature.

- **Opus 4.6: `hallucinated_reactions` appears uniquely.** Among the lowest-3
  failures, Opus 4.6 is the only variant that emits an extra
  cinnamoyl-oxazoline reaction on NC_2017 page 005. None of the other six
  variants hallucinate full reactions in their lowest-3 set (Gemini 3.1 Pro
  duplicates an existing reaction, which is a different failure mode).

- **Gemini Flash & Grok: `other` (scope-mismatched reactant hallucination)
  appears uniquely.** Both Gemini Flash and Grok produce a Partial-F1 = 0,
  Product-IoU = 1 collision on `GC_2015 page004` by populating reactants that
  gold leaves empty. This pattern does not appear in any other variant’s
  lowest-3 list. It is best treated as a new category — call it
  `scope_mismatch_reactants` — distinct from `hallucinated_reactions`
  because the reaction count is correct.

### Categories observed *not* to dominate anywhere

- `schema_failure`, `step_ceiling_exhaustion` and `condition_error` did not
  appear in any variant’s lowest-3 set. Every variant’s schema_conformance
  was `True` across all 16 images, no `*.meta.json` records `steps == 16`
  among the low-scoring images, and where conditions diverged from gold the
